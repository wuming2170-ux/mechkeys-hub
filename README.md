# MechKeys Hub - Mechanical Keyboard Affiliate Site

A niche affiliate website focused on mechanical keyboards, built with pure HTML/CSS/JS.

## Site Structure

```
mechkeys-hub/
├── index.html          # Homepage - Best keyboards 2025
├── 60_percent.html     # 60% compact keyboards
├── 65_percent.html     # 65% compact keyboards
├── tkl.html            # Tenkeyless keyboards
├── full-size.html      # Full-size with numpad
├── best-value.html     # Budget picks under $100
├── switches.html       # Switch type guide
├── data/
│   └── products.js     # Product data + affiliate links
└── assets/            # CSS/JS if needed
```

## Next Steps

### 1. Amazon Associates Application
Apply for [Amazon Associates](https://affiliate-program.amazon.com/) to get your affiliate tag (e.g., `mechkeyshub-20`).

### 2. Update Affiliate Links
Replace all Amazon links in `data/products.js` with your own affiliate tag:
- Find: `tag=mechkeyshub-20`
- Replace with: `tag=YOUR_TAG`

### 3. Deploy
- Push to GitHub and connect to Vercel/Netlify
- Or host on any static hosting

### 4. SEO Setup
- Register Google Search Console
- Submit sitemap
- Set up Google Analytics
- Consider Bing Webmaster Tools

### 5. Content Expansion
- Add individual product review pages
- Create comparison tools
- Add "Best Keyboards for Gaming" / "Best Keyboards for Typing" landing pages
- Build internal linking structure

## Revenue Model
- Amazon Associates (3-10% commission)
- Display ads (Google AdSense)
- Affiliate programs from keyboard vendors

## Tech Stack
- Pure HTML5 + Tailwind CSS
- Vanilla JavaScript
- Static hosting (Vercel/Netlify)
- No backend required

## Getting Started
Simply open `index.html` in a browser to preview.
